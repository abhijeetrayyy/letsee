# docs/design

The redesign of letsee, started 3 October 2026 and revised the same day after the owner rejected the first colour direction. **On anything visual, any layout, any flow, or how a feature behaves on screen, this folder wins over every older document in `docs/`.** Product rules decided elsewhere (no streaks, notifications only for what a person did, the private diary, cost discipline) still stand.

Read in this order:

1. `PHILOSOPHY.md` — *Someone else is in the room.* People first, cinema between them: the thesis, the graphite room where colour comes only from films and faces, ten principles, the voice, what letsee will never ship, and how to decide when unsure.
2. `RETHINK.md` — every feature taken apart: the new object model, the five destinations, Home in each of its states, rooms between people, the pass, *Us* visibility, a verdict on each of 54 features, and how to tell whether it works.
3. `SYSTEM.md` — every token (colour, type, space, shape, motion, icons, imagery), every component's anatomy, and the page templates.
4. `PAGES.md` — every route, the new ones and the shell: each page's job, what is there today, the new order of blocks, where people appear, what done means.
5. `EXECUTION.md` — how the change reaches every route and every component instance: phases, gates, migrations, the tracking table, limits, cost guardrails, the definition of done.
6. `00_current_state.md` — the audit the rest is measured against.
7. `research/` — five sourced notes: colour on dark (01), type, space and motion (02), designing for two people (03), competitor interfaces (04), flow, structure and accessibility (05).

A visual board — palette, type, the pieces and the key screens on a phone — is a private claude.ai artifact, *Someone Else in the Room*.
